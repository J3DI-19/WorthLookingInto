# Neuralink Inspired Website

A multi-page frontend web project inspired by the official Neuralink website, created for academic web programming practice and UI/UX recreation.

This project focuses on replicating the modern dark-themed design language, immersive layout, animated scrolling sections, background video effects, and structured multi-page navigation seen in the original Neuralink website while being built entirely for educational purposes.

> This project is a student-made educational recreation and is not affiliated with or endorsed by Neuralink.

---

## Project Overview

This website was developed as a web programming project to recreate the look and feel of the official Neuralink website using core frontend technologies only.

The project emphasizes:

* clean dark UI design
* animated visual presentation
* smooth page transitions
* immersive landing page experience
* responsive structure
* content-focused layout
* frontend-only implementation

The website includes multiple pages such as Home, About, Technology, News, and Contact, each styled independently while maintaining a consistent design system.

## Key JavaScript Features

### Scroll Animation System

The Technology page uses scroll-based interaction where:

* images zoom dynamically while scrolling
* text overlays fade in/out
* sections activate based on viewport position

This creates a presentation-style storytelling experience.

### Interactive Button Logic

Simple JavaScript interactions include:

* hidden message reveal
* countdown interaction handling

## Design Philosophy

The goal was not just to copy the original website visually, but to understand:

* layout architecture
* user flow
* visual hierarchy
* animation timing
* frontend structure
* page consistency
* modern web design principles

This project was built as both a learning exercise and a design recreation challenge.
